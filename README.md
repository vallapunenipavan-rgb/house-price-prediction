🏠 House Price Prediction Using Linear Regression
📌 Project Overview

This project predicts house prices using Linear Regression, a supervised machine learning algorithm.
The model is trained on housing data with features such as area, number of bedrooms, location-related factors, etc., to estimate the price of a house.

The goal of this project is to understand:

Data preprocessing

Exploratory Data Analysis (EDA)

Building and training a Linear Regression model

Evaluating model performance

🚀 Technologies Used

Python

NumPy

Pandas

Matplotlib / Seaborn

Scikit-learn

📊 Dataset

The dataset contains information related to houses, including:

Size of the house

Number of rooms

Location features

Price (target variable)
